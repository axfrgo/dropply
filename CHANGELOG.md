# Changelog

## 1.0.0 - 2026-05-14

- Released the first packaged Dropply Smart Drops baseline
- Added premium desktop UI pass with source context, local labels, tags, suggested actions, and lifecycle state
- Added local deterministic Smart Drop classification for text, files, images, PDFs, browser bundles, relay imports, and direct imports
- Added item open, copy, download, delete, pending, completed, and revoked actions
- Added Smart Drop metadata storage and migration columns on the existing item stream
- Added relay/direct metadata round-tripping while preserving older peer compatibility
- Added hosted pair dashboard Smart Drop display and web-created Smart Drop metadata
- Added companion TUI support for Smart Drop search, preview, open, pending, completed, and revoked workflows
- Added window pin mode groundwork
- Added Windows MSI and NSIS release packaging
- Added release, security, and open-core documentation
- Added GitHub publication and production-readiness docs
- Added checksum generation and Windows release workflow scaffolding
- Added hosted auth foundation for Google OAuth, magic links, passkeys, and sessions
